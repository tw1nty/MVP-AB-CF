# Pathway design system

Students compare a degree plan on a laptop in a bright advising room or library, so the interface uses light surfaces, crisp dividers, and legible blue actions.

## Color and typography

Restrained blue brand accent, navy text, cool neutral canvas, and green for accepted changes. Define colors with OKLCH. Use a native sans-serif family with a compact scale and tabular figures.

## Layout

200px sidebar, compact page header, horizontal degree-progress strip, one unified “What matters most to you?” panel above comparison rows. It contains numbered single-select choices on the left, accepted savings and graduation on the right, a contextual explanation underneath, and a Continue action. The section remains sticky on large, tall screens. No nested cards. Course comparisons use aligned columns and expandable detail. At narrow widths, collapse the sidebar and stack comparison columns with both summary metrics side by side. The full panel scrolls normally on narrow or short screens so it does not obscure course decisions.

## Components

Consistent 8px button radii, 10px panel radii, 1px dividers, native form controls, plain-text status badges, and restrained line icons. Primary blue is reserved for actions and selected controls. No decorative motion.


## Comparison variants

Version A preserves status filters and the original mixed list. Version B presents accepted swaps, pending suggestions, and dismissed suggestions as ordered sections on one page, with no status tabs. Accepted changes use the existing green state treatment and an aggregate savings figure. A separate preview-only A/B switch preserves in-session decisions.
